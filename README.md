# Machine Language Game

A three-part text adventure that teaches music production basics —
MIDI, rhythm and song structure, and Ableton Live 12.

Built for someone who knows what music they like but has never opened
a DAW before. Each game takes about 15–20 minutes. Play in any order.

Made in collaboration with Claude AI- designed by me. 
wildcreatrix.net

## ▶ Play it

**[Launch the trilogy →](https://kristinbot31.github.io/machine-language-game/)**

Works in any browser. No install. No account. Progress saves locally.

## The three games

- **Game 01 — Machine Language.** Reverse-engineer a sealed drum machine.
  Learn what MIDI is, what it does, and how every digital instrument
  speaks the same secret language.

- **Game 02 — Pressure & Release.** A booker calls. The headliner bailed.
  You have 90 minutes to build a 45-minute set from scratch — and learn
  how rhythm, structure, and tension actually work.

- **Game 03 — First Session.** Late at night, in front of a blank Ableton
  session. Build a track from empty browser to exported WAV. Session View,
  drums, bass, mixing, the works.

A 15-page printable companion is included as a PDF. Covers every

## Built for

Anyone curious about making electronic music — particularly the dark,
body-music end of the spectrum (EBM, industrial, techno, digital hardcore).
The fundamentals work for any genre, but the examples and aesthetic lean
toward Atari Teenage Riot, Die Sexual, Front 242, and the broader 125 BPM
warehouse universe.
